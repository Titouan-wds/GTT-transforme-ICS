? Comment importer le fichier dans mon agenda

Avant le premier import : créez un agenda dédié (par exemple « Planning »). Vos postes ne se mélangent pas à vos rendez-vous personnels, vous pouvez partager uniquement cet agenda, et en cas d'erreur il suffit de le supprimer pour tout annuler.
📱 iPhone / iPad (Apple Agenda)
  1. Touchez Télécharger le fichier .ics, puis ouvrez le fichier : bandeau de téléchargement de Safari, ou app Fichiers → Téléchargements.
  2. L'app Calendrier propose d'ajouter les événements : touchez « Ajouter tout ».
  3. Choisissez l'agenda de destination (votre agenda « Planning »), puis validez.
  4. Si rien ne se passe à l'ouverture : envoyez-vous le fichier par e-mail et touchez la pièce jointe dans l'app Mail.

📄 Apple : partager des calendriers iCloud sur l'iPhone ▶️ Vidéo : partager un calendrier iCloud sur iPhone (en anglais)

💻 Mac (app Calendrier)
  1. Si besoin, créez d'abord l'agenda dédié : Fichier → Nouveau calendrier (choisissez un compte iCloud pour pouvoir le partager).
  2. Fichier → Importer…, sélectionnez le fichier .ics, puis cliquez sur Importer.
  3. Choisissez le calendrier de destination et validez.
  4. Astuce : vous pouvez aussi simplement glisser le fichier sur la fenêtre Calendrier.

📄 Apple : importer ou exporter des calendriers sur Mac

🟦 Google Agenda (sur ordinateur)
  1. Ouvrez calendar.google.com sur un ordinateur.
  2. Pour créer l'agenda dédié : à gauche, « + » à côté de « Autres agendas » → Créer un agenda.
  3. Puis « + » à côté de « Autres agendas » → Importer (ou ⚙️ Paramètres → Importer et exporter).
  4. Sélectionnez le fichier .ics, choisissez l'agenda de destination (attention : par défaut, c'est votre agenda principal), puis cliquez sur Importer.

⚠️ L'application mobile Google Agenda (Android et iPhone) ne sait pas importer de fichier : l'import se fait uniquement depuis un ordinateur.

📄 Google : importer des événements dans Google Agenda

🤖 Android
  1. Si votre agenda est Google Agenda : faites l'import depuis un ordinateur (voir la rubrique Google ci-dessus). Les événements apparaîtront ensuite automatiquement sur le téléphone.
  2. Certaines applis d'agenda de constructeur (Samsung Calendar, par exemple) proposent d'importer le fichier quand on l'ouvre depuis Fichiers → Téléchargements : essayez, sinon passez par l'ordinateur.
📧 Outlook
  1. Outlook.com / Outlook sur le web / nouvel Outlook : Calendrier → Ajouter un calendrier → Charger à partir d'un fichier → Parcourir → choisissez le fichier et le calendrier de destination → Importer.
  2. Outlook classique pour Windows : Fichier → Ouvrir et exporter → Importer/Exporter → « Importer un fichier iCalendar (.ics) ou vCalendar » → sélectionnez le fichier → choisissez Importer.

📄 Microsoft : importer un calendrier dans Outlook.com / Outlook sur le web 📄 Microsoft : importer des calendriers dans Outlook (Windows)

👥 Partager l'agenda avec vos proches
  1. Google Agenda (sur ordinateur) : survolez l'agenda dans la colonne de gauche → ⋮ → Paramètres et partage → Partager avec des personnes en particulier → ajoutez les adresses e-mail et choisissez le niveau d'accès.
  2. Apple (iCloud) : dans Calendrier, touchez Calendriers → ⓘ à côté de l'agenda iCloud → Ajouter une personne. Les invités ont besoin d'un compte Apple ; sinon, activez le calendrier public pour obtenir un lien de lecture seule.
  3. Choisissez bien le droit d'accès : lecture seule pour informer, modification seulement pour les personnes qui doivent pouvoir changer vos postes.

📄 Google : partager votre agenda ▶️ Vidéo Google Workspace : partager son agenda (en anglais) 📄 Apple : partager un calendrier sur iCloud.com

🛠️ En cas de problème
  • Événements en double : l'import ajoute toujours les événements, il ne remplace rien. Pour une nouvelle période, réglez « Du / Au » sur les jours pas encore importés. Pour tout refaire : supprimez l'agenda dédié, recréez-le et réimportez.
  • Horaires décalés : les horaires sont exprimés à l'heure de Tahiti (UTC−10) ; vérifiez le fuseau de votre agenda (Google : ⚙️ Paramètres → Fuseau horaire).
  • Rien ne s'importe / message d'erreur : vérifiez que le fichier se termine bien par .ics et n'a pas été renommé en .txt lors du téléchargement.
  • Les événements sont dans le mauvais agenda : c'est que l'agenda de destination n'a pas été choisi. Le plus simple : supprimer cet import et recommencer en sélectionnant l'agenda « Planning ».
  • Un poste a changé : modifiez directement l'événement dans votre agenda, inutile de tout réimporter.
